# HTML Forms and Styling Lab

Solutions for the "HTML Forms and Styling" lab from the SoftUni HTML and CSS course.

## Projects

1. **P01_LoginFormImages**: login form with image icons
2. **P02_LoginForm-font-awesome**: login form with Font Awesome icons
3. **P03_LoginForm-BGImages**: login form with background-image icons
4. **P04_ContactForm**: contact form
5. **P05_ArrangingTheWidths**: form with arranged widths

## Technologies

- HTML5
- CSS3

## How to run

Download the repository, open a project folder, and open the `.html` file in your browser. Keep the `images` folder next to the HTML file so the pictures load.
